[Conheça o ShootFlow →](https://shootfloow.pages.dev)

## ⚙️ Como o ShootFlow foi pensado tecnicamente

O produto foi estruturado como uma aplicação web orientada a fluxo de trabalho. Em vez de espalhar informações entre planilhas, conversas e agenda, cada job percorre etapas claras: **novo contato → orçamento → fechado → sessão marcada → edição → entrega → pagamento**.

- **Gestão centralizada:** clientes, jobs, compromissos e informações financeiras ficam conectados dentro do mesmo fluxo.
- **Interface para trabalho real:** o painel prioriza visão rápida de jobs, datas, pendências e pagamentos.
- **Automação com IA:** o usuário pode informar um job por texto, áudio ou conversa. A IA transforma o conteúdo em dados estruturados para revisão antes de salvar.
- **Integração com rotina do fotógrafo:** atalhos aceleram o contato pelo WhatsApp, e mensagens de atendimento podem ser geradas conforme cada etapa do job.
- **Assinatura digital:** o acesso Pro inclui teste gratuito e checkout apresentado via Stripe.
- **Uso no celular:** a experiência foi planejada para funcionar no navegador do celular e poder ser adicionada à tela inicial.
- **Personalização:** cada espaço pode receber nome, cores e logo próprios.
